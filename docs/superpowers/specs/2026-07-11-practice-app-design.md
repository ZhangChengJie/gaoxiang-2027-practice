# 高项 2027 练习平台设计

## 目标

将本目录下的考点、600 道题和论文资料做成可部署到 Cloudflare Pages 的 React 练习平台。

## 架构

- React + Vite + TypeScript；不直接维护静态 HTML 页面。
- 题目与论文字段在构建时由本地 Markdown 导入并转换为 TypeScript 数据。
- `localStorage` 保存答题记录、错题 ID 和章节进度；无账号、无数据库、无服务器状态。
- Cloudflare Pages 托管构建产物，项目名即默认域名：`gaoxiang-2027-practice.pages.dev`（以部署结果为准）。

## 页面与功能

1. 首页：总体进度、最近错题、章节入口、八大绩效域优先入口。
2. 章节：阅读范围、50 题训练、答后立即解析、章节进度。
3. 错题本：按章节过滤、重做、正确后移除、清空。
4. 专题：计算、案例、ITTO、论文、八大绩效域。绩效域专题包含八个域、每域说明与专项练习。
5. 论文：每个章节提供对应论文范围/写作提示；另提供六个高分论文题材。

## 数据与质量约束

- 12 个原章节各 50 题，题目与答案解析完整；绩效域专题用原第 05 章题目拆分并补充 40 道绩效域题，总量不少于 640。
- 本地存储版本化、JSON 解析失败自动回退为空状态。
- 不收集个人信息；清除浏览器数据即可彻底删除学习记录。
- 构建、类型检查、生产预览和 Pages 部署均为验收门槛。
