# 20-英文术语专项：30 道选择题（含答案解析）

围绕《信息系统项目管理师教程（第 4 版）》与 PMBOK 第 7 版相关术语原创编写，采用英文题干和英文选项，训练阅读与概念辨析。中文解析包含关键词释义、正确理由与干扰项区别，覆盖绩效域、原则、裁剪、挣值、风险应对与敏捷。

## 01. Which performance domain focuses on engaging people who can affect or be affected by a project?

A. Team
B. Stakeholder
C. Measurement
D. Delivery

**答案：B**

**解析：** 关键词 engaging 指促进参与，affect or be affected 指影响项目或受项目影响。干系人绩效域关注识别、分析并促进干系人参与；团队绩效域主要关注项目团队的文化与协作。

## 02. Creating a collaborative culture and enabling a high-performing project team belong primarily to which performance domain?

A. Team
B. Planning
C. Delivery
D. Uncertainty

**答案：A**

**解析：** 关键词 collaborative culture 是协作文化，high-performing team 是高绩效团队。团队绩效域关注团队发展、领导力与协作；规划域主要关注计划，交付域关注成果，不是题干的直接重点。

## 03. Selecting a predictive, adaptive, or hybrid approach is primarily addressed by which performance domain?

A. Measurement
B. Project Work
C. Stakeholder
D. Development Approach and Life Cycle

**答案：D**

**解析：** 关键词 predictive、adaptive、hybrid 分别是预测型、适应型、混合型。开发方法和生命周期绩效域关注适合项目的开发方式及阶段安排；测量域提供绩效信息，不负责这一核心选择。

## 04. Progressively elaborating plans as more information becomes available is central to which performance domain?

A. Delivery
B. Team
C. Planning
D. Stakeholder

**答案：C**

**解析：** 关键词 progressively elaborating 是渐进明细，plans 是计划。规划绩效域通过持续规划细化行动以应对新信息；交付域关注成果和价值，团队域关注协作能力，不能替代规划的核心职责。

## 05. Managing project processes, removing impediments, and supporting knowledge sharing primarily belong to which performance domain?

A. Project Work
B. Delivery
C. Measurement
D. Uncertainty

**答案：A**

**解析：** 关键词 impediments 是障碍，knowledge sharing 是知识共享。项目工作绩效域关注流程、资源和工作执行环境；交付域强调成果与价值，测量域强调信息分析，不是题干的直接活动。

## 06. Ensuring that project outputs support intended outcomes and business value is the main focus of which performance domain?

A. Planning
B. Uncertainty
C. Delivery
D. Team

**答案：C**

**解析：** 关键词 outputs 是输出或交付物，outcomes 是成果，business value 是业务价值。交付绩效域关注范围、质量与预期成果；仅制定计划或建设团队不能代替价值交付的结果要求。

## 07. Using reliable metrics and trends to support timely project decisions is the focus of which performance domain?

A. Stakeholder
B. Measurement
C. Development Approach and Life Cycle
D. Team

**答案：B**

**解析：** 关键词 metrics 是指标，trends 是趋势，timely decisions 是及时决策。测量绩效域用可信信息评价绩效并支持行动；干系人域关注参与，团队域关注协作，不是指标分析的核心领域。

## 08. Addressing ambiguity, complexity, volatility, and risk is central to which performance domain?

A. Delivery
B. Planning
C. Measurement
D. Uncertainty

**答案：D**

**解析：** 关键词 ambiguity、complexity、volatility、risk 分别是模糊性、复杂性、波动性和风险。不确定性绩效域综合处理这些因素；测量提供信息但不等同于全部不确定性管理活动。

## 09. Which project management principle asks the team to continually evaluate whether the project supports intended benefits?

A. Create a collaborative project team environment
B. Focus on value
C. Build quality into processes and deliverables
D. Demonstrate leadership behaviors

**答案：B**

**解析：** 关键词 intended benefits 是预期收益，Focus on value 是聚焦价值。该原则要求持续审视成果对收益和价值的贡献；质量和领导力虽支持成功，但不能替代本题直接考查的价值判断。

## 10. Recognizing how changes in one project component can affect other components reflects which principle?

A. Focus on value
B. Optimize risk responses
C. Recognize, evaluate, and respond to system interactions
D. Embrace adaptability and resiliency

**答案：C**

**解析：** 关键词 component 是组成部分，system interactions 是系统相互作用。将项目作为相互关联的系统评估变更影响符合系统思维原则；单独优化某项风险不能覆盖组件间的整体联系。

## 11. Acting responsibly, honestly, and with care for resources reflects which principle?

A. Be a diligent, respectful, and caring steward
B. Navigate complexity
C. Tailor based on context
D. Enable change to achieve the envisioned future state

**答案：A**

**解析：** 关键词 responsibly 是负责任地，steward 是管家或受托管理者。勤勉、尊重和关爱体现责任与诚信；裁剪原则关注方法适配，复杂性原则关注系统特征，不是题干的伦理重点。

## 12. Examining multiple interacting factors and emergent behavior rather than assuming simple cause and effect supports which principle?

A. Demonstrate leadership behaviors
B. Focus on value
C. Create a collaborative project team environment
D. Navigate complexity

**答案：D**

**解析：** 关键词 interacting factors 是相互作用的因素，emergent behavior 是涌现行为。驾驭复杂性要求识别关联、反馈与涌现；简单按单一因果处理不能充分应对复杂项目。

## 13. What does tailoring mean in project management?

A. Removing all controls to speed up delivery
B. Using every process identically on every project
C. Adapting the approach, governance, and processes to the project context
D. Replacing stakeholder engagement with templates

**答案：C**

**解析：** 关键词 tailoring 是裁剪，project context 是项目情境。裁剪是根据规模、风险、环境等调整方法、治理和过程，同时保持有效性；不是取消控制，也不是对所有项目机械套用全部过程。

## 14. Which factor should guide the selection of a project development approach?

A. The level of requirements uncertainty and the need for frequent feedback
B. The alphabetical order of process names
C. A rule that all projects must use the same approach
D. The number of pages in the project charter alone

**答案：A**

**解析：** 关键词 requirements uncertainty 是需求不确定性，frequent feedback 是频繁反馈。方法选择应适应需求与交付特征；流程名称顺序、统一套用或仅按章程页数都不能反映项目的实际需要。

## 15. In earned value management, what does Earned Value (EV) represent?

A. The actual cost of completed work
B. The approved total project budget
C. The forecast cost of remaining work
D. The budgeted value of work actually completed

**答案：D**

**解析：** 关键词 Earned Value 是挣值，budgeted value 是预算价值。EV 衡量实际完成工作的预算成本；实际成本是 AC，总预算是 BAC，剩余工作估算是 ETC，不能用这些指标替代 EV。

## 16. A project has EV = 80 and AC = 100. What is its Cost Performance Index (CPI)?

A. 1.25
B. 0.80
C. 20.00
D. 1.00

**答案：B**

**解析：** 关键词 Cost Performance Index 是成本绩效指数。CPI=EV/AC=80/100=0.80，小于 1 表示成本效率低于预算。1.25 是 AC/EV 的倒数结果，20 是差额而不是无量纲的指数。

## 17. A project has EV = 90 and PV = 100. Which statement about its Schedule Performance Index (SPI) is correct?

A. SPI is 0.90, indicating that the project is behind schedule
B. SPI is 1.11, indicating that the project is ahead of schedule
C. SPI is 10.00, indicating that the project is on schedule
D. SPI cannot be calculated without AC

**答案：A**

**解析：** 关键词 Schedule Performance Index 是进度绩效指数，behind schedule 是进度落后。SPI=EV/PV=90/100=0.90，小于 1 表示落后；此公式不使用实际成本 AC，1.11 则倒置了分子分母。

## 18. If current cost performance is expected to continue, which formula estimates the total cost at completion?

A. EAC = BAC - AC
B. EAC = AC + BAC
C. EAC = BAC / CPI
D. EAC = EV / PV

**答案：C**

**解析：** 关键词 Estimate at Completion 是完工估算，current cost performance 是当前成本绩效。该假设下 EAC=BAC/CPI；BAC-AC 是剩余预算，EV/PV 是 SPI，均不是预测总成本。

## 19. Reducing the probability or impact of a threat is known as which risk response?

A. Exploit
B. Mitigate
C. Share
D. Accept

**答案：B**

**解析：** 关键词 threat 是威胁，probability 是概率，impact 是影响，Mitigate 是减轻。减轻主动降低威胁概率或影响；开拓、分享针对机会，接受则不等同于主动降低风险。

## 20. Purchasing insurance to shift part of the financial impact of a threat to a third party is an example of which response?

A. Avoid
B. Enhance
C. Exploit
D. Transfer

**答案：D**

**解析：** 关键词 insurance 是保险，third party 是第三方，Transfer 是转移。保险将部分财务后果按约定转给保险方；规避是消除威胁，提高与开拓则用于机会，不符合题干。

## 21. A threat is outside the project manager's authority and requires an organizational decision. Which response is most appropriate?

A. Escalate
B. Exploit
C. Ignore
D. Enhance

**答案：A**

**解析：** 关键词 authority 是权限，organizational decision 是组织层级决策，Escalate 是上报。超出项目授权的威胁应移交有权限的层级处理并明确责任；忽视无助于应对，开拓和提高适用于机会。

## 22. Assigning the best available specialist to ensure that a valuable opportunity occurs is an example of which response?

A. Accept
B. Transfer
C. Exploit
D. Mitigate

**答案：C**

**解析：** 关键词 opportunity 是机会，ensure 是确保，Exploit 是开拓。开拓旨在确保机会实现；接受不主动保证实现，转移与减轻通常针对威胁，不符合题干对积极收益的要求。

## 23. What is a residual risk?

A. A new risk created by implementing a response
B. A risk remaining after a response has been implemented
C. Any risk that must be escalated
D. A risk that has no owner

**答案：B**

**解析：** 关键词 residual risk 是残余风险，remaining 是仍然存在。残余风险是采取应对后仍留下的风险；应对措施新产生的风险称二级或次生风险，不应与残余风险混淆。

## 24. In an agile project, who is primarily accountable for ordering the product backlog to maximize product value?

A. The project sponsor alone
B. The external auditor
C. Every supplier independently
D. The product owner

**答案：D**

**解析：** 关键词 product backlog 是产品待办事项列表，product owner 是产品负责人。产品负责人对按价值排序和有效管理待办事项负责；发起人提供支持，审计方或供应商不自动承担该产品责任。

## 25. Which agile event is mainly used to inspect how the team worked and identify process improvements?

A. Sprint retrospective
B. Sprint planning
C. A contract negotiation
D. A final acceptance ceremony

**答案：A**

**解析：** 关键词 retrospective 是回顾，process improvements 是过程改进。迭代回顾检视协作和工作方式并制定改进；迭代规划确定目标与工作安排，不替代对已完成迭代的反思。

## 26. What is the main purpose of a Definition of Done?

A. To forbid future changes to the product
B. To replace all stakeholder communication
C. To establish a shared understanding of the quality conditions for completed work
D. To record only the hours spent by each developer

**答案：C**

**解析：** 关键词 Definition of Done 是完成的定义，shared understanding 是共同理解。它规定成果达到完成状态所需的质量条件；不等于冻结产品，也不能替代沟通或简化为工时记录。

## 27. What does a burnup chart typically show?

A. Only the number of project risks
B. Completed work over time, often together with total scope
C. Only the remaining budget at completion
D. The personal performance ranking of team members

**答案：B**

**解析：** 关键词 burnup chart 是燃起图，completed work 是已完成工作。燃起图展示累计完成量，常同时绘制总范围以观察范围变化；剩余工作趋势常用燃尽图，个人排名不是其目的。

## 28. Which life cycle is generally suitable when requirements are stable and major deliverables can be planned early?

A. An adaptive life cycle with no planning
B. A life cycle selected only by team size
C. A life cycle that prohibits change control
D. A predictive life cycle

**答案：D**

**解析：** 关键词 stable requirements 是稳定需求，predictive life cycle 是预测型生命周期。需求明确、可提前规划时通常适用预测型；它仍允许受控变更，不能理解为禁止变更或无需规划。

## 29. What is the main purpose of a Work Breakdown Structure (WBS)?

A. To decompose the project scope into manageable work packages
B. To rank all threats by probability
C. To replace the approved cost baseline
D. To document only communication channels

**答案：A**

**解析：** 关键词 Work Breakdown Structure 是工作分解结构，work packages 是工作包。WBS 对项目范围进行层次分解以便管理；风险排序、沟通渠道与成本基准虽有关联，均不是其主要功能。

## 30. Which process obtains formal acceptance of completed project deliverables in the process-based framework?

A. Estimate Costs
B. Identify Risks
C. Validate Scope
D. Plan Resource Management

**答案：C**

**解析：** 关键词 formal acceptance 是正式验收，deliverables 是可交付成果，Validate Scope 是确认范围。该过程取得客户或发起人的正式接受；控制质量核实正确性，成本估算及资源规划不承担验收职责。
