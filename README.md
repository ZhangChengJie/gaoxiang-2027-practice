# 高项 2027 练习平台

React + TypeScript + Vite 构建的移动优先练习平台，**微信小程序风格 UI**。

## 功能

- **21 个主题、921 道选择题**（另有 40 道自动生成绩效域题）：全知识域覆盖，每题含 4 选项、答案与解析，答题后立即显示
  - 2026-10-14 v2：12—15 章选项重排（答案不再集中在 B）、承上题改为独立题、去重、补全短解析；新增 10 道网络图题与 30 道英文术语题；`src/data/questionBank.test.ts` 校验题库格式与答案分布
  - 2026-10 更新：按 2021—2026 九个考期真题统计走向，重建 01—06 核心章（信息化/治理工程/整合范围进度/成本质量资源/绩效域/ITTO 为真题式题型），新增 17 考试走向高频、18 法规与职业道德、19 运筹学
- **专项训练**：
  - 绩效域 · 计算题 · **法律法规·职业道德** · ITTO 高频链路 · 案例分析 · 记忆与复盘
  - **考试走向·高频必刷** · **科学基础·运筹学**
  - **易错考点**（动态提取高频错题） · **综合模考**（随机 75 题）
  - 六周冲刺 · **2026 真题相似专项**
- **今日任务**：先复习到期错题，再做 30 道新题（优先正确率低的章节）
- **机考模拟**：按真题知识域分布抽 75 题、150 分钟倒计时、交卷统一出分与分章得分，英文题在最后；中途刷新不丢答案
- **练习小结与正确率**：每轮结束显示正确率、用时、错题；首页各章显示正确率（<60% 红 / 60–70% 橙 / ≥70% 绿）
- **错题本**：答错时标记错因（不会 / 犹豫 / 粗心 / 会但慢）；答对后隔 1 / 3 / 7 天再复习，到期连续答对 4 次才移出；按到期与错因筛选、按章节练习
- **进度备份**：导出 / 导入 JSON，换设备或清缓存前使用
- **论文范围**：每章完整论文范围、采分点、练笔动作、关键词
- **微信小程序风格 UI**：白底绿主色、底部 Tab 导航、移动端优先

## 本地运行

```bash
npm install
npm run dev
```

运行检查：

```bash
npm run test
npm run build
```

## 技术栈

- React 19 + TypeScript 6
- React Router v7
- Vite 8 + Vitest
- localStorage（无后端）
- Cloudflare Pages

## 部署

```bash
npm run deploy
```
